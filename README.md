# business-dashboard
Interactive business dashboard built with Python, Pandas and Streamlit.

This project allows users to analyze sales data, identify top-performing products and visualize revenue metrics through an interactive dashboard.

Preview
assets/dashboard.png

Features:
    Sales data analysis
    Revenue calculation
    Top-selling product identification
    Interactive business dashboard
    Revenue visualization by product
    Data table exploration

Tecnologies:

    Pandas
    Streamlit
    Data Analysis
